# agentfault — Tier-A baseline results (MRCBench, offline)

> Generated by `scripts/chaos/agentfault/eval/eval_agentfault_tierA.py` (deterministic; RF/Random seeds 0-4). Scorer = `m9_score.mrcbench` (MRCBench 四族). Ranking mechanism reused from `eval_agentchaos` (per-agent binary RF -> predict_proba -> argsort). Entity space = 4 in-process agents (single-root).

- Rows: 108 | faulted (`injected==1`): **96** | rooted (scored): **96** | zero-root **excluded** from the localization macro: **12** (kind breakdown of the excluded rows: `normal`×12; these are negatives — clean `normal` reps plus any injection that did not diverge / `inject_failed`; empty GT -> ranking undefined).
- **Constant-Synthesizer prior (majority-class baseline):** always blaming `Recommendation_Synthesizer` gives Hit@1 = 36/96 = **0.375** (the Synthesizer is the root in 36 of the 96 rooted cases). Any localizer must beat this trivial prior to be meaningful.
- Candidate space = 4 agents. **Random and Contract-oracle are the two reference rails**; RF is a *supervised feature-separability ceiling*, NOT a peer baseline.

## Honest caveats (read before the numbers)

- **4-candidate space makes @3/@5 near-ceiling.** With a single root always among the 4 agents, **Hit@5 = FullHit@5 = 1.000 trivially** (top-5 ⊇ all 4), and a random ranker gets Hit@3 = 0.75. **K=1 is the only discriminative headline.**
- **Single-root degenerate identities (not independent numbers):** Recall@R ≡ Hit@1, FullHit@K ≡ Hit@K, avg@K ≡ Hit@K, NDCG@1 ≡ Hit@1 (all follow from |G|=1). NDCG@3 is the only K>1 number that adds rank information (reciprocal-log of the root's position within top-3). The MRCBench scorer still emits all four families + avg@K + mrr; the tables show the non-redundant subset.
- **RF ceiling under group-aware CV is confounded for the 3 hallucinate analyzers** (EVAL_NOTES 3c): each analyzer is the root in exactly ONE combo, so LeaveOneGroupOut removes its only positive class -> its per-agent RF degenerates to a constant -> near-random Top@1. This is split-degeneration, NOT proof of infra-blindness; read alongside the deterministic tracks.
- **Corrected-channel trivial heuristic is near-random everywhere; the RAW channel is the artifact detector — that contrast is the contribution.** On the CORRECTED span-duration channel (the default infra channel, which subtracts the injection sub-LLM overhead) the trivial heuristic is near the 0.250 floor on every family (hallucinate 0.278, structured 0.333-0.417), context_drift 0.028. On the RAW channel it spikes to 0.889 on hallucinate — but that spike is purely the injection sub-LLM's latency artifact, NOT genuine localizability, which is exactly why corrected is the channel of record. The contract oracle is the mirror image (perfect on structured, abstains on hallucinate). An aggregate number would hide this.
- **Deterministic oracle > supervised content ceiling under group-aware CV.** On wrong_item_pick the oracle scores 1.000 but the RF-content ceiling only 0.567: `response_asin_is_sentinel` lives in a SINGLE combo, so LOGO holds it out of training and the RF cannot use it. The perfect content signal is only exploitable without training (oracle) or when it recurs across ≥2 combos (format's `contract_check` -> RF-content = 0.450). This is why the deterministic tracks, not the supervised ceiling, are the dataset's headline localizers.

## Design notes / judgment calls (flagged for review)

- **Trivial heuristic ranking rule** = per-agent span-duration z-score (vs that agent's own distribution over all 108 rows, GT-blind) + a status==ERROR bonus. Status is constant `UNSET` so only duration contributes. Global scalars (`recommendation_confidence`, `e2e_latency`) are **deliberately excluded** because they are not per-agent and cannot rank AMONG the 4 agents. An alternative 'low-confidence -> blame Synthesizer' domain heuristic would lift the trivial score on the 2 low-confidence format subtypes (missing_field/type_violation, conf=0.50) only, but that is really a degenerate contract-oracle (it needs the domain map confidence->Synthesizer), so it is folded into baseline #4 rather than #2.
- **Post-correction, the naive 'infra sees hallucinate' intuition does NOT hold.** One might guess the duration heuristic localizes hallucinate (the sub-LLM rewrite adds latency); on the RAW channel it appears to (0.889), but that is the injection artifact. Once the artifact is subtracted (CORRECTED channel) hallucinate drops to 0.278 — near-random, like the structured families (0.333-0.417). The honest reading: span-duration signals do not localize hallucinate; the apparent RAW-channel skill is an injection-mechanism footprint, not infra localizability. **context_drift is ~random (0.028 ≈ the 0.250 floor) on every Tier-A method here** — it is a pure content deletion (an upstream agent's message is stripped from the downstream input), so the system recovers with NO latency signature and NO needle/asin/contract signal. That near-random result is the honest, EXPECTED finding: span-duration / content-flag localization cannot see context_drift; it motivates the separate structural track.
- **RF-content feature set** = per-agent `conv_<A>_text_len` (4) + deterministic content bools (`divergent_needle_present`, `response_asin_is_sentinel`, `toolcall_asin_is_sentinel`, `contract_check_matches_expected`); RF-infra = the e2e/HTTP/host scalars + per-agent span numeric cols. `conv_text_len` is counted as content (text-derived), matching the eval_agentchaos split.

## Anti-trivial audit

> Concept referenced from `scripts/qa/anti_trivial_gate.py` (trivial baseline vs random floor; single-feature GT-encoding). Re-derived at agent granularity here.

- **Random floor** (analytic): Hit@1 = 1/4 = **0.250**; Hit@3 = 0.750; Hit@5 = 1.000.
- **Infra is near-blind by construction:** span_Sequence_Recommender_status=['UNSET'], span_User_Behavior_Analyzer_status=['UNSET'], span_Product_Analyzer_status=['UNSET'], span_Recommendation_Synthesizer_status=['UNSET']; http_status=['200']; error_span_count=['0']. No infra status/error column varies -> no covert single-feature infra encoding of GT.
- **Single-feature content encoding (this is the designed signal, reported honestly):**

| feature | fires (rows) | root agents when it fires | FP on clean | encodes |
|---|---|---|---|---|
| `divergent_needle_present` | 36 | Product_Analyzer, Sequence_Recommender, User_Behavior_Analyzer | 0 | hallucinate family (does NOT name which analyzer) |
| `response_asin_is_sentinel` | 12 | Recommendation_Synthesizer | 0 | wrong_item_pick -> Recommendation_Synthesizer (names agent) |
| `contract_check_matches_expected` | 12 | Recommendation_Synthesizer | 0 | format_violation -> Recommendation_Synthesizer (names agent) |

- **Finding (content):** `response_asin_is_sentinel` and `contract_check_matches_expected` each fire with **0 false positives on clean rows** and each names exactly **Recommendation_Synthesizer** -> a single content feature trivially solves the STRUCTURED families (this IS the contract-oracle upper bound; it is the dataset's designed deterministic signal, documented, not a covert leak). `divergent_needle_present` fires only on hallucinate but does **not** name which analyzer (all 3 analyzers share it) -> no single feature trivially encodes the *agent-level* GT for hallucinate, which is why that family is genuinely hard.
- **Finding (infra):** the best SINGLE infra feature separates the 36 Synthesizer-fault cases from the rest with only **AUC=0.764** (`e2e_latency_ms`); all others are ~0.5-0.65. So the RF-infra ceiling reaching Hit@1=1.000 on the structured families is **multi-feature aggregation + analyzer-elimination** (the analyzer RFs, trained on the hallucinate latency artifact, confidently predict not-root, so a merely moderate Synthesizer score wins the argmax) — NOT a single-feature infra leak, and it does NOT transfer to hallucinate (structural LOGO degeneration).

## Specificity / false-alarm note (12 zero-root rows)

- **Contract oracle:** abstains on all 12 zero-root rows (no structured content signal) -> **0 false alarms** (perfect specificity on clean, by construction). This is the honest specificity headline.
- **RF-infra ceiling:** any-agent-positive fired on 0.467 of zero-root rows; **RF-content ceiling:** 0.617 (avg over seeds). ⚠️ These are NOT reliable specificity estimates: LOGO holds out the single `normal` group entirely, so the per-agent classifiers see **no clean rows** when scoring the clean rows -> they over-fire. This is the specificity analogue of the single-group split-degeneration (EVAL_NOTES 3c), not evidence that the models are trigger-happy in deployment.
- **Trivial span-anomaly & Random:** pure rankers with no abstention -> always emit a top-1 -> false-alarm rate is 1.0 by construction (not applicable as a detector; localization-only).
